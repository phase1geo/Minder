Nodes make up the structure of the mind map itself.  Each node in the mind map has a relationship to other nodes within the map. Nodes can contain text, notes, images, stickers and other visual indicators. The visual look of a node can be changed within the Styles sidebar with the following options.

### Border Style

Each node can have a border drawn around its content or it can have no border drawn at all. Selecting a node and changing the border by clicking on a toggle button will immediately change the border used to draw the selected node.

### Border Width

If the node has a border, the thickness of this border can be changed with this slider. Sliding to the left will decrease the width of the drawn border. Sliding to the right will increase the border width.

### Color Fill

If the selected node has a border, this switch, when enabled, will fill the body of the node with the same color as the border; otherwise, the internal space of the node will be transparent, taking on the color of the canvas background color. 

### Margin

This slider affects the space around the node. Sliding the slider to the left will decrease the amount of space between the node and its bordering nodes (effectively making the mind map more dense). Sliding the slider to the right will increase the amount of space around the node.

### Padding

This slider affects the amount of space between the border of the node and the rest of the node content. Sliding the slider to the left will decrease the amount of space around the content while sliding to the right will increase the node spacing.

### Font

Clicking the font button and choosing a new font and/or font size will apply that font and font sizing to the selected node(s) when the font selection window is closed.

### Text Alignment

Allows text to be aligned to the right, left or center of the node text area.  The alignment will be especially noticable when the node text occupies more than one line.

### Width

This style value impacts the maximum default width of the node. Sliding the slider to the left will decrease the width of the node while sliding to the right will increase the width of the node. When entering text in a node, when the node size reaches this width value, text will be wrapped and the node will group horizontally.

### Enable Markup

If this switch is enabled, Minder will parse the node text as Markdown text, applying text styling/coloring according to the parsed Markdown. Disabling this option will treat the node text as plain text and will not format the text accordingly.
