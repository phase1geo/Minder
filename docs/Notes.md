# Sidebar Note Fields

The note field will accept Markdown text and will stylize the text according to that Markdown.  Right-clicking within the note field will display a contextual menu providing various text editing functions as well as Markdown markup shortcuts. If text is selected, selecting a Markdown menu item will wrap the text in the markup. If text is not selecting, the Markdown markup will be inserted and the insert cursor placed in the proper location for inserting text.

### Emoji

You can insert any of the system emoji in this text field by using Control-. (period) and selecting any of the available emoji in the window.

### Unicode Characters

Unicode characters can be inserted by entering the backslash character following whitespace.  A completion field will be displayed, allowing you to search for the appropriate Unicode character to insert.

### Node Links

Links to nodes can be pasted within the note field which will create a link to that node (even if the node is in a different mind map document).  Simply select a node, copy it to the clipboard, and paste the resulting text into the note field. A link to a node will look like `@Node_x` where `x` will be a number. To view the linked node, hover the mouse over the link, hold the Control key while left clicking on the mouse.

### URL Links

URL Markdown links can also be clicked using the Control key and left mouse click gesture. The default application that your system has configured to handle the URL will be launched with the given URL handle.
