# Creating a Flow Diagram

Minder is primarily a mind mapping application and has automatic layout features that make it ideally suited for this purpose.  However, Minder's higher level goal is to help user's  bring their ideas to life and sometimes a mind map is not the best way to present information.  Sometimes using a flow control diagram is the best way to present this information, and Minder has the ability to make these types of diagrams using root nodes and connections.
