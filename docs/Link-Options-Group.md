A link is a single connection between a child and its parent.  Links are associated with the child node, such that selecting a node and changing the link style options will affect the link between the selected node and its parent.

Link colors are automatically derived from the color of the child node. Colors are not considered to be part of the styles so they are not changed in the styles sidebar. To change colors of links, select on the **Current** tab in the sidebar and make the changes to the selected child nodes. All other styling changes to branches should be handled in the Style sidebar.

### Line Dash

Links between a child and a parent node can be a solid line or a dashed line with various dash patterns.  Selecting one of the line dash types in the dropdown menu will immediately be displayed in the canvas.

### Line Width

You may change the width of the link line using the associated scrollbar, sliding to the left will decrease the width of the line while sliding to the right will increase the line width.

### Link Arrow

If the associated switch is enabled for this option, a small arrow will be drawn in the direction of the parent to the child. Disabling this option will remove the arrow.

### Link Arrow Size

Sliding the link arrow size slider to the left will decrease the size of the links with arrows while sliding to the right will increase them.  Four sizes are provided: Small, Medium, Large, and Extra Large.  This option is only changeable if the Link Arrow is enabled.
