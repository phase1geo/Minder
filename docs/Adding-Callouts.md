# Callouts

A callout is a brightly-colored text box that is associated with a node which is meant to call special attention to the node within the mind map.  The callout color is defined by the map theme.  Callouts can be stylized with the [Style Tab](Callout-Options-Group.md) in the sidebar.  Callout text can include any text that is also valid for node text, including Markdown formatting, inline LaTeX, links, etc.

## Adding a Callout

To add a callout to a node, select the node and use the contextual menu to select the `Change Node > Add Callout` option.  This will add the callout to the current node and put its text into text editing mode.  Enter any desired text and hit the return key to exit text editing mode.  Alternatively, use the configured keyboard shortcut for adding a callout when the node is selected.

## Removing a Callout

To remove a callout from a node, do any of the following:

* Select the callout and hit the Delete key.
* Select the callout, right-click to display the contextual menu associated with callouts and select the `Delete` option.
* Select the node associated with the callout and hit the 'o' key (or whatever keyboard shortcut is associated with adding/deleting a callout).
* Select the node associated with the callout, right-click to display the node contextual menu, and select the `Change Node > Remove Callout` option.

## Callout Selection

To select a callout associated with a node, select the node and use the **Shift-O** keyboard shortcut (or whatever the currently configured keyboard shortcut is within the preferences window).  Alternatively, right-click to display the node contextual menu and choose the `Select > Callout` menu option.

If a callout is currently selected, you can select the associated node by using the same keyboard shortcut.  Alternatively, right-click to display the callout contextual menu and click on the `Select Node` menu option.
