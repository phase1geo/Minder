# Callout Options

Callouts are associated with nodes but have their own styling options. Callouts contain text and have a "pointer" on them which points to the node that it is calling attention to. Callout colors are dictated by the theme and are not a part of the style of the callout. The following options are available for styling callouts.

### Text Font

Clicking this button will display a font selection dialog which will allow you to change the font and font size used to display the text in the selected callout. When the dialog is closed, the selected font and font size will be immediately applied to the selected callout.

### Text Alignment

Allows text to be aligned to the right, left or center of the node text area. The alignment will be especially noticable when the node text occupies more than one line.

### Padding

Sliding this slider to the left will decrease the amount of space between the callout text and its box border while sliding to the right will increase this space.

### Pointer Width

The callout pointer width is the width of the base of the pointer (the portion of the pointer attached to the callout itself). Sliding this slider to the left will decrease the width of the base of the pointer (making the pointer skinnier) while sliding it to the right will increase the base pointer size.

### Pointer Length

The callout pointer length is the distance between the callout and the called out node (the pointer attaches to both the callout and the node). Sliding this slider to the left will decrease the pointer length (bringing the callout closer to the node) while sliding to the right will increase the pointer length.
