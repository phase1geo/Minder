# Creating a Mind Map

Mind maps are made up of ideas also known as "nodes" which are related to each other either through parent/child relationships using "links" or through user-defined relationships using "connections".

The following subpages will walk you through the process of creating these various elements of the mind map:

- [Creating Nodes](Creating-Nodes.md)
- [Adding Images](Adding-Images.md)
- [Adding Tasks](Adding-Tasks.md)
- [Adding Notes](Adding-Notes.md)
- [Adding Connections](Adding-Connections.md)
