# Stickers Tab

Stickers are a great way to add meaning to a node, connection or other area of the mind map with a visual image.  You can attach a sticker to a node and a connection.  You can also place a sticker anywhere else within the mind-map.

It is important to note that attaching a sticker to a node or connection will allow the sticker to change locations as the mind map is modified, whereas placing a sticker on the mind map itself will not automatically change the position of the sticker as the mind-map is modified.

All available stickers can be viewed from the Sticker panel in the sidebar.

### Searching for Stickers

Each sticker in the sidebar panel has text associated with it which describes the sticker.  To find a sticker for a keyword, simply enter the keyword in the search field at the top of the sticker panel.  The list of matching stickers will be immediately filtered as you type.

### Favoriting a Sticker

At the top of the list of stickers is a special section dedicated to showing you stickers that you have marked as favorites.  This group is meant to help you find stickers that you use often more quickly.  To favorite a sticker, find it in the panel, right-click on the sticker to display the contextual menu and select the **Favorite** menu option.  To unfavorite a sticker, find the sticker in the panel, right-click to bring up the contextual menu and select the **Unfavorite** menu option.  Favoriting a sticker will be remembered by the application.

### Adding a Sticker to a Node

To add a sticker to a node, make sure that the node is within view in the mind map canvas, bring up the sticker panel, and drag and drop the sticker from the panel to the node.  A highlight will be displayed around the node when the sticker is droppable.  The sticker will be placed on the left side of the attached node.  To replace the sticker with a new one, simply drag and drop a new sticker onto the node.  To remove a sticker, right-click the node to display the contextual menu and select the **Remove Sticker** menu option.

### Adding a Sticker to a Connection

Adding a sticker to a connection is the same process as attaching a sticker to a node.  Simply drag and drop the sticker onto the connection to add it.  The sticker will be displayed to the left of the connection text (if text exists).  A connection can have a sticker added without text being displayed for the connection.

### Adding a Sticker to the Mind Map

To add a sticker anywhere else on the mind map, simply drag and drop the sticker to the desired location on the mind map.  Stickers on mind maps can be resized by dragging the resize handle to the left or right.  To delete a sticker, select it, and hit the Delete key.
