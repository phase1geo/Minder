# Connection Options

Connections are manually created links between any two nodes within the mind map. Generally, the linked nodes are not direct relatives of each other. These connection lines can optionally contain a text box and can indicate direction with arrows. The following styling options apply to connections:

### Line Dash

This dropdown allows the user to make the connection line solid or various dash patterns. Selecting a new line dash will immediately affect the selected connection visually.

### Arrows

This dropdown allows the user to change the arrows drawn on the connection. You can select no arrows, unidirectional arrows in either direction, and a bidirectional arrow. Changing this value will immediately update the arrows on the selected connection.

### Arrow Size

Sliding the arrow size slider to the left will decrease the size of the arrow heads while sliding to the right will increase them.  Four sizes are provided: Small, Medium, Large, and Extra Large.

### Line Width

Sliding this slider to the left will decrease the width of the connection line while sliding it to the right will increase the width of the connection line.

### Padding

Sliding this slider will change the amount of space between the connection text and its border. Sliding to the left will decrease the padding space while sliding it to the right will increase the padding space.

### Title Font

Clicking this button will display a font selection dialog, allowing you to change the type of font used in connection text along with its size. When the dialog is exited, the font changes will have an immediate impact on the selected connection.

### Text Alignment

Allows text to be aligned to the right, left or center of the node text area. The alignment will be especially noticable when the node text occupies more than one line.

### Title Width

Specifies the maximum default size of connection text boxes. If the text within the box attempts to exceed this size, line wrapping will occur and the title box will increase in vertical size.
