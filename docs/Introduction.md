# What is Minder?

Minder is a mind-mapping application with many features that make it ideal for capturing, organizing and visualizing your ideas.

Minder boasts a rich feature set to help you better understand, plan, and structure your best ideas while keeping UI largely out of the way, making it an ideal tool to keep in your toolbox.

### Robust Presentation

Minder has automatic node layout features that allow you to focus on putting down your ideas in a tree-like format. Links and nodes can be colorized to help differentiate trains of thought. Images and stickers can be added to nodes to help convey meaningful information. Notes can be added to a node to provide even more information to an idea. Tags are useful for categorizing. Each node in the mind-map can be made a task which can be checked as complete. Priorities can be assigned to nodes. Callouts and node groups can be added as well to call attention to specific areas of your document. Even richer information like mathematical formulas and tables can now be inserted into nodes. Node links can tie a node to another within the same map or an entirely different one.

The entire tree can layout can be changed on the fly to help make the information easier to understand while themes can help make your mind-maps uniquely your own.

### Connect Unrelated Ideas

Connections can be made between any two nodes in the mind-map, helping to show relationships beyond parent/child. Connections can display optional titles, direction, color and may even contain notes of their own. In a single button click, all connections can be hidden or reshown within the mind map.

### Fast Input

Keyboard shortcuts exist for almost every feature and action and can be reconfigured from their defaults. The brainstorming feature allows you to quickly jot down unstructured ideas that can be inserted into the map structure later while the quick entry feature allows you to enter outline-style text to insert new trees or branches.

### Powerful Viewing and Search Tools

Minder has support for zooming and a special viewing mode to help you focus on the current topic. It also has support for powerful searching and filtering to help you find the information that you need.

### Extensive Exporting

On the output side, Minder supports many different output formats to help it fit into your workflow, including native printing support.
