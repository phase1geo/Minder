Branches in the canvas are the lines drawn automatically between parent and child nodes. A branch belongs to the parent node, so selecting a node and changing the branch style will affect only the links between the selected node and its children.

### Style

The branch style represents the way that branches are drawn between nodes. The options are straight lines, squared lines, rounded-square lines, and curved lines. Clicking on one of these selection buttons will toggle the button state and affect the selected node branches.

### Margin

The branch margin slider controls the amount of space between parent and child nodes. Sliding the margin slider to the left will decrease the amount of space between nodes, making the node tree more condensed. Sliding the margin slider to the right will increase the amount of space between nodes.
