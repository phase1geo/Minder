# Priority Flags

Priority flags can be added to nodes labeled 1 through 5.  Each priority flag has a unique color to help distinguish it within the node:

* 1 = Red
* 2 = Yellow
* 3 = Green
* 4 = Blue
* 5 = Purple

Adding a priority flag to a node simply places the associated badge on the left-hand side of the node.  More than one of the same priority flag can be used throughout the mind map (for example, two or more nodes can both be labeled priority 1 if you choose).

Priority flags could be used to identify next steps in a project, prioritize tasks, etc.

## Adding a Priority Flag

To add a priority flag to a node, simply select the node and hit the numerical key associated with the priority you want to set (i.e., hit **2** to add a priority of 2 to a node).  Alternatively, you can use the contextual menu when the node is selected and go to the `Change Node ‣ Priority` menu to choose a priority to set.

You can change the priority of a node with a set priority using the same method.

## Removing a Priority Flag

To remove a priority flag from a node that has one, select the node and hit the **0** (zero) key.  Alternatively, you can remove the priority flag by using the contextual menu's `Change Node ‣ Priority ‣ Clear Priority` menu item.
